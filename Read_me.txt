I was trying to follow OOP and Event Driven Architecture. So classes know as little about each other as possible, logic of each class is encapsulated in that class, different systems talk to each other in abstracted manner.
For commercial project I would add extra layers of abstraction in logic, and also would to use tick for updating timer information and HUD. But for simple demo project with not many game systems current implementation should be good enough.
I did not make matchmaking system for game build since it was not mentioned as requirement. So multiplayer is available in engine only.
Also I did not put any effort into gamedesign since it is not the focus of this test. But I am relatively competent in field of gamedesign.
Ready to discuss and improve any aspect of the test project if I need to demonstrate some specific skill or knowledge in some specific field.
